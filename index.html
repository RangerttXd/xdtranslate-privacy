XdTranslate 隐私政策

适用于 XdTranslate 1.1.2。

本机翻译

XdTranslate 在你发起整页翻译、正文双语或划词翻译时读取需要翻译的文字。默认模式通过浏览器的本机翻译功能处理这些文字。首次使用某些语言时，浏览器可能下载语言包。XdTranslate 不会在默认模式下向扩展开发者或 OpenAI 发送待翻译文字。

可选的 AI 精译

当你启用 AI 精译、连接另行运行的本机助手并发起翻译时，扩展将待翻译文字和语言选项交给本机助手。助手用你提供的 API Key 将这些数据发送到 OpenAI API 以获取译文。提交的文字可能包含个人信息，是否使用此功能由你决定。

助手在 API 请求中设置 store: false。OpenAI 对 API 数据的处理及保留取决于其政策和你的账户设置。OpenAI API 数据说明。

设置和配对信息

扩展将语言和翻译引擎设置保存在浏览器本地。AI 助手的配对码保存在当前浏览器会话中。API Key 由本机助手读取，扩展不会保存 API Key。你可以关闭助手或切回本机翻译，也可以从 Edge 移除扩展及其本地设置。

XdTranslate Privacy Policy

This policy applies to XdTranslate 1.1.2.

On-device translation

When you request a full-page, bilingual article, or selected-text translation, XdTranslate reads the text needed for that translation. By default, it uses the browser’s on-device translation feature. The browser may download language packs when you first use certain languages. In this mode, XdTranslate does not send the text to the extension developer or OpenAI.

Optional AI translation

If you enable AI translation, connect the separately run local helper, and request a translation, the extension passes the text and language selections to the helper. The helper sends this data to the OpenAI API using the API key you provide. Submitted text may include personal information. You choose whether to use this mode.

The helper sets store: false on API requests. OpenAI handles and retains API data according to its policies and your account settings. See OpenAI’s API data documentation.

Settings and pairing

The extension stores language and translation engine settings locally in the browser. It stores the helper’s pairing code in the current browser session. The local helper reads the API key. The extension does not store it. You can close the helper, switch back to on-device translation, or remove the extension and its local settings from Edge.
